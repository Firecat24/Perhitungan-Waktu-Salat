# 🌙 Aplikasi Perhitungan Waktu Salat (Prayer Times Calculator)

Sebuah aplikasi web berbasis Python yang dirancang untuk menghitung jadwal 5 waktu salat secara akurat menggunakan algoritma astronomi (Ilmu Falak). Proyek ini mengintegrasikan logika perhitungan matematis kompleks ke dalam antarmuka web yang mudah digunakan oleh pengguna awam.

## 🚀 Fitur Utama
* **Kalkulasi Akurat:** Menghitung waktu Subuh, Zuhur, Asar, Magrib, dan Isya berdasarkan parameter titik koordinat lokasi.
* **Antarmuka Web Dinamis:** Dibangun menggunakan kerangka kerja Flask dengan *routing* yang terstruktur.
* **Desain Responsif:** Memanfaatkan HTML dan CSS untuk menyajikan data jadwal salat dalam tampilan yang rapi dan mudah dibaca.

## 🛠️ Teknologi yang Digunakan
* **Backend:** Python (Flask Framework)
* **Frontend:** HTML5, CSS3
* **Algoritma:** Logika perhitungan astronomi/Ilmu Falak kustom (Tanpa bergantung pada API pihak ketiga)

## 📂 Struktur Proyek
Proyek ini mengimplementasikan arsitektur standar Flask:
* `website.py` - Berisi *routing* utama dan logika *backend* aplikasi.
* `/templates` - Menyimpan *file* HTML untuk antarmuka pengguna.
* `/static/styles` - Menyimpan *file* CSS untuk penataan gaya visual (UI).
